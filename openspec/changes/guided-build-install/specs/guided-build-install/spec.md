## Purpose

为需要自行制作工具安装包或安装工具并构建 Webman 项目的使用者提供一次启动的引导流程。使用者只需选择包类型、安装与项目目录；工具负责下载、校验、构包、安装自检与项目验证，并持续说明真实进展及结果。

## ADDED Requirements

### Requirement: 一次启动源码构包
系统 SHALL 为 Windows x64 与 macOS ARM64 源码提供可直接执行的原生文件入口。系统 MUST 自动取得受摘要锁定的启动 PHP，不要求预装 PHP、创建脚本或复制多段命令。

#### Scenario: 选择轻量或完整包
- **WHEN** 使用者执行源码入口并选择轻量或完整包
- **THEN** 系统解释两者下载/离线差别，自动准备对应平台锁定输入、构包、校验产物并进行私有目录安装自检，成功显示实际产物路径、类型、大小和耗时

#### Scenario: 构包后选择安装
- **WHEN** 构包与自检成功
- **THEN** 系统在同一流程提供安装刚生成的包或结束的选择，不要求使用者自行找命令或解压后再执行命令

### Requirement: 独立启动直接下载安装
系统 SHALL 为 Windows x64 与 macOS ARM64 提供按版本固定的单文件下载安装入口。macOS默认下载物 SHALL 用保留执行权限的启动器ZIP封装该文件，使用者仅需系统打开归档及启动文件，MUST 不要求chmod或手写解压命令。使用者只需取得并执行入口文件、选择轻量或完整，系统 MUST 自动下载该平台安装包、校验外层SHA-256、解压并进入安装及项目下一步。不得要求使用者对照Release资产、手工解压、预装PHP或拼接命令。

#### Scenario: 从独立文件下载安装
- **WHEN** 使用者在无源码、无PHP、无已安装Builder的环境执行官方版本setup入口并选择包类型
- **THEN** 系统显示版本和轻量/完整差别，自动取得入口绑定的HTTPS包并核验准确摘要，在新私有目录解压后调用包内引导安装；不额外要求使用者执行另一文件

#### Scenario: 下载损坏或非本版本的包
- **WHEN** 下载文件与入口绑定的摘要不符、下载失败或归档不安全
- **THEN** 系统不执行其中任何程序或安装代码，显示真实失败及安全重试/Issues入口，并保留非零结果

#### Scenario: 生成版本固定的下载入口
- **WHEN** 维护者从同平台同版本的已构包轻量与完整产物生成setup入口
- **THEN** 生成过程核对实际文件摘要/大小/平台/版本，入口包含确定的两种包地址和摘要，且现有packager默认JSON协议保持不变

### Requirement: 一次启动安装与下一步
系统 SHALL 在交付的 Windows/macOS 安装包中提供原生启动文件，并使用现有安装事务。安装前 MUST 显示目标位置及 PATH 行为，由使用者选择继续或取消。

#### Scenario: 离线或已持有的安装包
- **WHEN** 使用者解压匹配平台的包并执行安装入口
- **THEN** 无需预装 PHP或编写命令即可确认安装，系统自动校验包、安装并通过新安装的绝对路径验证版本，再提供构建项目或结束选项

#### Scenario: 完整包离线与拒绝安装
- **WHEN** 完整包安装没有网络，或者使用者选择取消
- **THEN** 完整包使用包内锁定组件且禁止联网回退；取消操作不写入用户安装目录或 PATH

### Requirement: 选择项目自动构建验证
系统 SHALL 在安装成功后允许使用者选择 Webman/SaiAdmin 项目目录，并自动串联现有项目 build 与 verify；不要求手动 doctor、切换目录或复制下一条命令。

#### Scenario: 项目构建成功
- **WHEN** 使用者选择有效项目且构建成功
- **THEN** 系统自动验证新产物，显示真实 dist-aot 路径与校验范围，并说明本机结构/完整性验证不代表 Linux 部署或业务运行验收

#### Scenario: 目录错误或项目构建失败
- **WHEN** 选择无效目录或构建返回失败
- **THEN** 系统展示原因并允许重选/重试/结束，不继续执行依赖失败结果的验证或宣称成功

### Requirement: 可理解的状态与故障恢复
引导流程 MUST 持续显示当前阶段、实际可观测下载量/比例或耗时，最多 5 秒补充一次长任务存活状态；任何结束结果 SHALL 含成功或失败、人话原因及下一步。失败 MUST 保留真实子进程退出码和错误，提供日志位置及 https://github.com/supdger/webman-aot-builder/issues 入口，不自动发送日志。

#### Scenario: 下载失败与摘要不匹配
- **WHEN** 下载网络失败或文件摘要不匹配
- **THEN** 流程停止依赖步骤，分别显示网络/证书/HTTP/完整性原因及安全重试建议，保留可安全续传材料，拒绝使用损坏输入

#### Scenario: 长任务与窗口退出
- **WHEN** 下载、解压、构包或安装耗时较长，或者双击启动的流程结束
- **THEN** 可读阶段状态持续可见，未知总量不编造百分比，交互窗口保留结果待使用者选择结束

### Requirement: 自动化及隔离兼容
现有 CLI、机器 JSON 输出与参数默认语义 SHALL 保持兼容。新增引导入口在非交互输入下 MUST 不无限等待、不隐式安装，并支持明确参数执行或给出清晰错误。自检 MUST 只安装本次产物至新建私有目录且不改真实用户 PATH。

#### Scenario: 自动化及输入结束
- **WHEN** 原机器命令运行，或引导输入遇到 EOF/非交互环境
- **THEN** 原协议保持可解析；引导流程按明确选择执行或安全退出，不把 EOF 当安装同意，不因 pause/read 卡住流水线

#### Scenario: 路径与干净安装
- **WHEN** 源码、包或项目位于含空格/中文的路径，且用户已有旧安装
- **THEN** 参数保持原义，自检验证新包而非旧 PATH 命令，且不改变旧安装

### Requirement: 项目镜像排除系统元数据但保护真实源码
系统 SHALL 在项目源码快照与构建镜像中一致忽略任意层精确名称 `.DS_Store`。其他隐藏文件及真实源码 MUST 继续参与一致性校验；不能为避免误报关闭源码变化保护。交付安装包 MUST 包含相同修复。

#### Scenario: 系统元数据变化
- **WHEN** 根目录或嵌套目录 `.DS_Store` 新增、删除或修改
- **THEN** 源码指纹不因该元数据改变，镜像不包含该文件，合法项目构建可以继续

#### Scenario: 镜像期间真实源码变化
- **WHEN** 镜像创建期间真实源码新增、删除或修改
- **THEN** 系统阻止不一致镜像生效并清理本次候选，错误区分变化类型及具体相对路径，附重试建议；不输出文件内容、无界清单或未转义控制字符

#### Scenario: 引导入口保留真实原因
- **WHEN** 安装后的引导项目构建因真实源码变化失败
- **THEN** 终端显示底层变化类型/相对路径及恢复建议，保持非零结果，不继续依赖失败产物的verify；不得误报下载故障

### Requirement: 依赖兼容及衍生工具链身份
系统 MUST 将可选第三方适配绑定到已批准的版本、源引用、源码摘要与规则命中合同；未知或漂移输入 SHALL 在生成或编译前拒绝。兼容修复 MUST 保留依赖完整行为范围，不通过跳过类掩盖构建失败。重构 SDK 的库、完整头树与来源清单 MUST 共同受批准锁保护，正常及缓存消费者使用相同校验。

#### Scenario: 正常入口使用新 SDK
- **WHEN** 使用者安装匹配版本的轻量或完整包并构建适用项目
- **THEN** 系统从已核组件加载批准源码和 SDK，实际生成、编译、链接并验证产物，持续显示真实进展；不需要维护者替换运行中的工具路径

#### Scenario: 组件或缓存来源漂移
- **WHEN** 依赖源码、SDK 头文件、库、衍生清单或复用组件的非批准输入改变
- **THEN** 系统保留非零失败且停止依赖步骤，不编译或发布不一致产物；已发布旧版或其他平台通过不能替代当前输入验收
