# Webman AOT Builder v0.2.0 发布说明

本文记录截至 **2026-09-27** 的 v0.2.0 候选发布说明和验证证据。在线发布状态及
当前可下载资产请以
[v0.2.0 GitHub Release 页面](https://github.com/supdger/webman-aot-builder/releases/tag/v0.2.0)
为准；本文件不对页面当前状态作实时断言。

## 主要变化

- 产品、仓库、安装包与命令统一为 **Webman AOT Builder**、
  `supdger/webman-aot-builder` 和 `webman-aot-builder`。
- macOS Apple Silicon 与 Windows x64 安装器使用独立的新用户数据根。
  新版使用 `WEBMAN_AOT_BUILDER_HOME` 覆盖路径，不读取、覆盖或迁移
  v0.1.3 的旧用户缓存。
- 从 v0.1.3 切换需要安装新包并验证 `webman-aot-builder version`；
  旧版 `webman-aot self-update` 不会安装新命令或迁移目录。
- 项目编译仍生成 `dist-aot/`。这是 Linux 发布目录的技术名称，随新版保留。
- macOS PHP CLI 与独立 compiler-driver 按新的路径和标识重新构建。
  LGPL-2.1 许可文本与重链接材料另行提供，详情见
  [macOS runtime 源码与重链接材料](../macos-runtime-source.md)。

## 安装包名称

v0.2.0 安装包使用以下名称：

- `webman-aot-builder-0.2.0-macos-arm64.tar.gz`
- `webman-aot-builder-0.2.0-full-macos-arm64.tar.gz`
- `webman-aot-builder-0.2.0-windows-x86_64.zip`
- `webman-aot-builder-0.2.0-full-windows-x86_64.zip`

轻量包首次使用时下载并校验精简组件；完整包内含同一组件，可离线准备。
安装包及其 `SHA256SUMS.txt` 摘要以 GitHub Release 页面列出的资产为准。

未部署，不匹配发布锁。归档的当前在线发布状态和下载入口以

## 当前验证边界

- 新版 Mac CLI、compiler-driver 与运行时锁中的摘要一致；CLI 严格签名校验通过。
- relink 归档的逐文件清单及路径审计通过；在隔离解压副本进行 CLI 和
  compiler-driver 修改、重编译与重链接自测通过。
- 中立 Webman 的 Linux amd64 产物在无网络 Docker 容器内通过静态 ELF 检查，
  Workerman 启动成功，并对本地 HTTP 请求返回预期的 Webman 404 页面。这是
  容器 smoke，不是裸机、SaiAdmin 数据库业务或目标服务器验收。
- 截至上述验证快照，Windows 实机验收和裸机目标运行不在已有证据范围内；
  Docker 容器 smoke 不替代这些验收。新仓库与在线 Release 资产的当前状态请以
  Release 页面为准。
